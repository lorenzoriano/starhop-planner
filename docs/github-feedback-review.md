# GitHub feedback review

Reviewed against the published `113379a` app and the subsequent fixes. GitHub exposed 19 reports, issues [#1–#19](https://github.com/lorenzoriano/starhop-planner/issues); no issue #20 was available on repeated reads. The reports were checked against source, astronomical references, regression tests and an independent browser pass. This document records decisions, rather than treating every proposed implementation as a requirement.

## Sources and validation

- [SEDS Messier data](https://messier.lamost.org/seds/seds.org/messier/en/data.html), [RASC Messier table](https://calgary.rasc.ca/messiers.htm) and the [University of Arizona Messier list](https://skycenter.arizona.edu/sites/default/files/Messier_List.pdf) support the coordinate corrections.
- [Bright Star Catalogue ReadMe](https://cdsarc.cds.unistra.fr/ftp/V/50/ReadMe) and [original notes](https://cdsarc.cds.unistra.fr/ftp/V/50/notes.gz), especially HR 5958's variability note, distinguish historical nova maxima from ordinary brightness. [AAVSO's T CrB record](https://vsx.aavso.org/vsx/index.php?oid=10602&view=detail.top) records its broad magnitude range.
- The [Washington Double Star Catalog](https://crf.usno.navy.mil/wds/) is the reference for double-star identity/separation. Telescope-versus-binocular guidance is intentionally conservative; visual resolution depends on magnification, contrast, steadiness and eyesight.
- The independent baseline browser pass reproduced the sequence, chart-label, missing-target, mobile-popup, daylight, scroll, search and calendar-contrast defects. It qualified the broader scroll/search claims rather than repeating them uncritically.
- The regression suite passes 150 tests across 15 files, plus TypeScript and the production build. New checks cover corrected coordinates, image alignment, saved-ID migration, route overlap, planetary anchors, exact search, setting priority, stable lunar events, summer samples, bookmarks, polygon orientation and horizon label bounds.

The final independent browser pass checked 375/620/776/1440 pixel layouts, red mode, M8-first ordering, exact search, Back/reload, after-dark summer samples, explicit next-occurrence planning, named save destinations and wheel behavior. It found two additional UI defects (literal sample-time text and mobile popup border clipping); both were fixed and rechecked. Actual font measurements and unique keys for the two Serpens figures removed resize-related stale labels; centered placements keep long target names readable on small charts.

Parent browser verification matched the source Milky Way membership at 3,976 plotted catalog-star positions and repeated the same 3,976 checks after mirror/90° rotation. Offline target bookmarks, orientation persistence and saved-ID migration with merged notes and observing timestamps passed without browser errors.

Publication uses the repository's main-branch GitHub Pages workflow. The release is checked against its workflow result and public asset manifest.
